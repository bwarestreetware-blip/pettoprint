# Base44 integration

This directory is reserved for Base44 project configuration and resources.

The current repository was not previously initialized as a Base44 project, so this scaffold does not invent a Base44 app ID or configuration. Once Base44 connects/imports this repository, its generated `base44/config.jsonc`, entities, functions and types should live here.

Expected resources for the video editor:
- Project
- VideoAsset
- TimelineClip
- ExportJob
- TranscriptionJob
